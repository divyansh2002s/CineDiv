# CineDiv 1.2 changes

- Replaced the old visual identity with the selected black, gold and white cinema logo.
- Added the selected logo to the app header and launcher icon.
- Renamed Catalog to Cinema Vault / Vault.
- Added a one-tap clear button inside the search bar.
- Added Add buttons to Favorites and Watchlist.
- Favorites and Watchlist can now add a title from Cinema Vault or create a manual local title.
- Manual titles remain on the phone and never write to Google Sheets.
- Removed the local test title `test` with year `1940` from catalog parsing, cache migration and personal lists.
- Added a richer dark cinema UI, gold filters, improved cards, watched styling and stronger empty states.
- Kept full Google Sheet loading for all Movies and Shows rows.
- Version updated to 1.2.0.
